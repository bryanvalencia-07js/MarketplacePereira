# Reactiva Pereira

Marketplace orientado a apoyar y dar visibilidad a comercios de Pereira y su área metropolitana afectados por el terremoto del 10 de agosto de 2026.

## Estado actual

Actualmente se está desarrollando el backend de la aplicación.

El primer módulo implementado es Usuarios, mediante una API REST desarrollada con Node.js y Express.

## Tecnologías actuales

- Node.js
- Express.js
- CORS
- Nodemon
- JSON

## Módulo de Usuarios

La API cuenta actualmente con CRUD completo:

GET /api/usuarios

GET /api/usuarios/:id

POST /api/usuarios

PUT /api/usuarios/:id

DELETE /api/usuarios/:id
